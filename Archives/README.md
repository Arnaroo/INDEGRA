# Archives

This folder preserves earlier, now obsolete versions of INDEGRA, kept for
provenance only.

## old-pre-v1.2.0

A snapshot of the INDEGRA repository as it stood before the v1.2.0
"Echidna" release. It contains the original prototype R and Python
scripts (`INDEGRA_scripts/`) and a small test dataset (`Test_Data/`),
together with the README and licence that accompanied that version.

**This snapshot is obsolete and is superseded by the current INDEGRA
v1.2.0 release at the repository root.** The current release ships a
single self contained, pre compiled binary for Linux, macOS, and
Windows. New users should ignore the contents of this folder and follow
the instructions in the top level `README.md`.
